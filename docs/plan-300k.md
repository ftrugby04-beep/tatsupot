## 提案文 #2 Instagram・Facebook AI自動投稿システム

```

5. 初期構築の概算費用・納期
100,000円／約2週間（Meta側のアプリ審査期間は除く）

6. 月額運用費用の目安
投稿文生成：1投稿 約1〜3円、画像生成：1枚 約5〜10円 → 月100投稿で 約1,000〜1,500円
実行環境：Google Apps Script なら 0円

7. 納品物
ソースコード、設定手順書、運用マニュアル（納品可）
```

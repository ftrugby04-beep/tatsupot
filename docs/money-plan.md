# 30日で5万円 実行プラン（たつぽっと）

## 戦略：すでに作ったアプリを「実績」にして、小さな制作代行を売る

手元にある「AI議事録アシスタント」と「コーチング記録カレンダー」は、そのまま制作実績として見せられる。
「スマホで使える業務ツールを作ります」という受託を **ココナラ** で出し、制作作業は Claude Code が担当する。

**目標の内訳（どれか1つでも達成すれば5万円）**
- A: スタンダード 15,000円 × 2件 ＋ ライト 5,000円 × 4件 ＝ 50,000円
- B: プレミアム 30,000円 × 1件 ＋ スタンダード 15,000円 × 2件 ＝ 60,000円
- C: 知り合いのチーム・お店から直接受注 2〜3件（手数料なしなので一番効率がいい）

> ココナラの販売手数料（約22%）を考えると、手取り5万円には売上6.5万円程度が必要。直接受注（C）を混ぜるのが現実的。
